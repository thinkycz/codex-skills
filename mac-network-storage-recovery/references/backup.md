# Time Machine acceptance

Confirm the intended Mac, target share, capacity/quota, current compatibility and existing backup history. Use current Apple and device/project documentation for the exact macOS/device combination. Do not turn a past support claim into a permanent compatibility rule.

Verify discovery and authentication, then that Time Machine accepts the intended destination and completes a backup. Observe a completed status and target identity; where restore usability is requested, verify browsing/restoring a small explicitly selected file without overwriting the original. Do not remove existing backup history as a troubleshooting shortcut.

If only Finder file access was established, report that result and leave backup acceptance unverified. If a full initial backup is still running, report real progress rather than treating destination selection or “preparing” as completion. Verify reconnect/reboot behavior when it is part of the request.
