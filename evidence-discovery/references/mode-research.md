# Research

Define the question and search the narrowest authoritative source first. Separate source facts, freshness limits and inference. Use current primary sources where facts may have changed or authoritative attribution matters, following host browsing requirements. Stop when evidence supports the decision; do not turn a bounded question into an open-ended research project. No repository is required for external research.
