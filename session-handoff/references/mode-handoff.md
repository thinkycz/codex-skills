# Handoff

Write a compact continuation record with objective, current repository/branch identity, changes, completed evidence, unresolved decisions, blockers and next safe action. Include exact paths and commands only when useful. Distinguish observed facts, assumptions and stale claims. Do not paste the full conversation or secrets. A handoff should let the next session continue without redoing discovery.
