# Prepare

A sufficient inline user prompt is a valid specification. Normalize acceptance criteria, exclusions, dependencies and source conflicts before choosing proportional delivery tracking. Preserve agreed requirements: observed API behavior describes current capability, not authority to change scope. Keep inaccessible required integrations blocked unless deferral is accepted. Execute only if requested; a plan or PRD request ends with that artifact.
