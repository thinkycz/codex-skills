# Deliver

Resolve exact tickets and repository scope, including attachments, comments and prior implementation claims. Verify prior work against code and acceptance evidence. Implement only requested changes and record affected checks. Posting a closeout is a distinct external action: when explicitly requested, use that authorization without another confirmation for the same target/content scope. Inspect for duplicates, post once, read back, and report the result. If a write times out, inspect before retrying.

## Selected detail

Read only the reference matching the current question; these are not a mandatory sequence.

Preserve the repository's package manager, lockfiles, runtime requirements and deployment entrypoints unless the requested work requires an explicitly scoped change. A feature task is not permission for an incidental npm/pnpm migration. Choose validation by effective commands and inputs, avoid redundant equivalent runs, and still complete repository-required gates.

For a backend change consumed by an unmodified or separately delivered mobile app, read [mobile handoff](mobile-handoff.md).
