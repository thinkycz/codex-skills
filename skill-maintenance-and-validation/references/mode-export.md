# Export

Run the exporter from the chosen checkout with an explicit new destination. Resolve symlinks and reject source overlap or an existing destination; never replace recursively. Folder exports preserve package and root dependencies. Flattened exports are text references with binary/runtime disclosures, not executable installations. Exclude vendor-managed packages by default. Validate the exported layout and do not claim universal compatibility from successful copying alone.
