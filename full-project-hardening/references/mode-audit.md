# Audit

Build a risk-based map across architecture, authorization, data integrity, contracts, runtime flows, UI and release evidence. Inspect meaningful boundaries even when tests are green: direct service callers, nullable inputs, tenant/device state, concurrent writes, historical money totals, worker retries and rollback across external side effects. Record reproducible findings with severity, evidence and affected scope. Audit-only means no fixes, migrations, destructive test resets, deployments or external messages.
