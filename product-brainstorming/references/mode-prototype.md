# Prototype

Define the uncertainty, smallest experiment, success/failure signal, timebox and disposal boundary. Isolate prototype code/data from production. Explore logic, API shape or UI variants as needed; report learning and limitations. Prototype success is not production readiness and does not authorize promotion, deployment or live-data changes. Obtain direction only if the experiment materially expands the authorized task.
