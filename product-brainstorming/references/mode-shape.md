# Shape

Inspect known context and identify the actual unresolved decision. Already specified features bypass brainstorming. Compare meaningful alternatives with a recommendation; ask only questions that change direction. Use an inline design or existing document for modest work, a full design document only when useful/requested. Do not force an introductory consent-only turn. Visual aids are optional and host-appropriate, subject to normal tool permissions.
