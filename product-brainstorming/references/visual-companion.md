# Visual companion

Use a host-supported visual when it materially clarifies the current decision: a wireframe, state flow or focused comparison. Do not force a consent-only introductory turn or a browser/local-server requirement. Follow normal tool permissions and any applicable host skill. Prefer a low-fidelity artifact with realistic content and a short explanation. Stop using visuals when prose becomes clearer; no fixed gallery size or mandatory session-wide choice.
