# Review

Review the supplied prompt or document against clarity, completeness, consistency, verifiability, exceptions and scope. Cite precise ambiguities and their delivery impact. Distinguish defects in the requirements from implementation bugs. Rank blocking questions above optional polish. A concise inline review is sufficient; do not create a checklist file unless useful or requested.
