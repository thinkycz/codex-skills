# Clarify

Ask only questions that materially change scope, architecture, safety or acceptance. Inspect available evidence first; do not ask what the repository or supplied prompt already answers. State a defensible default for minor unknowns. Record confirmed answers in the existing source when authorized; do not turn clarification into implementation.
