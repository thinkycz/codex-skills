# Google Maps review replies

1. Confirm business and branch, then inspect the original review and existing owner reply. For an unanswered-review batch, skip reviews already answered; edit an existing reply only when requested.
2. Reply in the review's original language unless the user specifies otherwise, including for languages different from the surrounding admin UI. If a rating has no text, use the user's requested/default business language rather than inferring nationality from a name.
3. Address what the reviewer actually described in a warm, concise business voice. Acknowledge criticism without inventing the incident's cause, admitting unsupported facts, blaming staff or promising refunds/free items that were not authorized. Keep personal/order details out of public replies.
4. Prepare a draft when drafting is requested. Publish when the current request explicitly asks to answer/post those reviews, preserving that authorization across the batch. Do not send private messages as an additional action.
5. After submission, reload the same review and inspect the stored reply and language. If a save times out, check before retrying. Record pending moderation separately; a submitted reply is not proof it is already public.

Summarize completed, skipped and pending replies without reproducing private customer information.
