# Route

Use the requested outcome and authorization to choose one owner. A specified change goes directly to delivery; a plan does not authorize execution. Distinguish source intake, requirement review, implementation, verification and resumption. Load a helper only for a concrete question the owner cannot answer. Do not load every skill mentioned by a router.
