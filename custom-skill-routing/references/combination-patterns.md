# Conditional composition

Choose one owner; helpers answer a concrete missing question and return to it. Existing evidence is reusable.

- Ambiguous direction: product-brainstorming shape; proceed to delivery only when requested and sufficiently specified.
- Supplied designs: Figma or Stitch acquisition; spec-driven-development PRD only when needed/requested; design-to-traversable-app for an authorized multi-screen implementation.
- Ticket work: ticket-driven-delivery intake, review, plan, deliver or closeout according to the request.
- Existing plan: docs-driven-execution; session-handoff resume only when restart evidence is uncertain.
- Audit: full-project-hardening or frontend-design audit. Remediation needs authority.
- Completion: verification-before-completion verify/readiness/handoff according to the output needed.

Do not load successive owners merely because they appear in this list. A small known fix does not need a lifecycle pipeline.
