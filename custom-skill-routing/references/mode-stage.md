# Stage

Inspect existing acceptance criteria, implemented slices, test evidence and blockers. Continue from the earliest incomplete dependency, not from a preset lifecycle beginning. An implementation-ready specification bypasses brainstorming and PRD creation. Green tests do not establish feature completeness or deployment identity. Reuse the working summary; route only unresolved work.
