# Decompose

Split by observable vertical outcomes, dependency order and independently verifiable acceptance. Give each slice inputs, owned files/interfaces, required checks and exit evidence. Mark parallel work only where shared schemas, fixtures and state will not conflict. Preserve completed slices on resume. Use workers only when permitted and when their bounded work leaves useful integration work for the lead.
