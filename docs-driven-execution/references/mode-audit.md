# Audit

Record material actions, approvals, failures and evidence in the existing tracker. Distinguish what the user authorized from what actually executed. Include target, scope and result; redact secrets. Reuse explicit authorization for the same action, not a materially changed target. An unavailable optional log should not block otherwise authorized safe work; disclose the gap. Audit-only requests do not authorize external messages or code changes.
