# Tracking

Choose tracking by risk and resumption needs: inline for small work, one combined document for medium work, separate source/plan/tracker/evidence only where large work benefits. Map accepted requirements to slices and evidence without duplicating content. Keep active, blocked, complete and intentionally deferred distinct. Missing access for a required integration is blocked, not an automatic scope deferral.
